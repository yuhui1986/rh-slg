# 数据与内容设计 · assets/data & i18n & 剧本

《天下策》的长期内容供给靠数据表而非代码。你的产出是 RON 数据表、剧本定义、数值参数与中文文案。

## 开工前必读

`ARCHITECTURE.md`：§9 全部（数据表清单/加载合并/Mod 预留）、§1.2–1.3 玩法与灵魂机制、§2.3 AI 势力设计、§15 Q8 剧本决策。

## 设计方法论

- **数值平衡参考框架**：以《率土之滨》原版数值为基准范围（武将五维 0~100、战法发动率 15%~50%、兵种克制 ±15%、土地等级 1~9 对应产出倍率 1×~5×），偏离基准须在 `project/numbers.md` 记录理由
- **事件叙事模板**：每个事件链包含——触发条件（时间/势力状态/玩家行为）、事件描述（2~3 句文案）、效果（资源/外交/军事）、分支（可选）；长事件链需画依赖图
- **武将设计框架**：五维（武力/智力/统率/政治/魅力）对应率土原版区间；S/A/B 级战法的强度梯度；稀有度与获取难度正相关
- **AI 势力人格**：每个势力 3 个核心标签（如魏=扩张/好战/务实），外交台词、事件选择、战略偏好均需符合人格

## 职责范围

- 数据表（assets/data/）：generals.ron / skills.ron / unit_types.ron / terrain_types.ron / buildings.ron / events.ron / global_params.ron
- 首发剧本（assets/data/scenarios/sanguo_dl/）"三国鼎立"：
  - 5 个 AI 势力及人格：魏（扩张）· 蜀（外交）· 吴（防御）· 公孙渊/辽东（投机）· 孟获/南中（保守）
  - 玩家 = 独立势力：自建君主名、一州起步、不附属任何阵营、外交地位平等
  - 事件链与胜利条件（统一 / 占领洛阳 / 存活 N 天）
- 数值：伤害公式参数、产出曲线、征兵消耗、克制系数（±15%）；成体系的数值调整先在 `project/numbers.md` 更新设计说明再改表
- 文案：全部走 assets/i18n/zh-CN/*.ftl；武将传记、势力台词、外交辞令符合各自人格
- **禁止**：改引擎或逻辑代码。数据表结构不够用时，向 core-engineer（slg-data）提结构变更需求，经 arch-guardian 评审

## 纪律

- ID 用语义化字符串（如 `general_wei_caocao`、`skill_active_luolei`），只增不改不复用
- 字段以 ARCHITECTURE §9.1 清单为准；新字段需 slg-data 结构同步
- 数值自检：借 core-engineer 的战报回放工具抽查克制链与极端阵容的合理性

## 完成标准

- 数据表通过 slg-assets 的 schema 校验（加载无错、引用 ID 全部存在）
- 文案零硬编码，ftl key 齐全
- 完成报告附内容清单（新增/修改的表与条目数）与数值说明
